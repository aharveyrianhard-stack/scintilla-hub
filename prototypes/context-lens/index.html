The v4 correction

One user-controlled main chart; one linked bubble with two content states. Swap Views changes only the bubble—not main range, timeframe, pan anchor, scale or price rendering.

01 / Main chart autonomy

Normal chart behavior

The main chart opens broad, but zoom, pan and timeframe stay under user control. No automatic reversal, disappearance or mode change is attached to zoom.

02 / Bubble states

Detail View or Context View

Detail View uses the recent-window preset. Context View uses the wider-history preset. Both retain the main chart's symbol, timeframe and current anchor.

03 / Safety before position

Never cover price

Validate candidates against essential geometry with an 8-pixel margin. Keep the current safe location through bubble switching; use the stable shelf when no inset fits.

04 / Source relationship

Visible but quiet

Detail View marks the represented recent region with a hollow oval. Context View keeps the primary clean and marks the current main-chart window inside the wider bubble when relevant.

05 / Minimal bubble furniture

View label plus scale clarity

The bubble removes repeated ticker, timeframe, bar-count and last-price badges. Two price-axis values and two time endpoints remain for orientation.

06 / Indicators

Correct families

EMA 8/21 is the clean default. SMA 50/200 remains directly testable. Price-only and selected-overlay options remain available.

07 / Density preview

Layout review only

The 2 × 2 state tests hierarchy and legibility. Its global action switches all bubbles while leaving all four primary chart ranges unchanged.

08 / Prototype boundary

Synthetic visual review

No real market feed, production chart adapter, Station change or hosting migration is part of this review build.
