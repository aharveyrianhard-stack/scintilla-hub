Page spec

Purpose
One place to reach Scintilla's prototypes and tools, grouped by purpose, with an honest readiness label on each.
Owner
Scintilla. The Indicator Lab entry and its home are owned independently by Indicator Lab.
Maturity
Review home, version 0.1. A static page; no tool on it is certified by it.
Inputs
catalog.json in this folder (titles, descriptions, status and addresses) and the shared navigation baseline v0.1.
Outputs
Links only. The page reads nothing at run time, stores nothing and sends nothing.
Release
Published by the Hub's normal reviewed deployment. Being published is not the same as being verified.
Verification
Automated checks keep this page and catalog.json in agreement, keep labels to the evidence (Existing tool, never Working, without functional proof) and keep every link a listed address. Reachability was checked on 18 Sep; function was not.
Private material
Review notes and work items stay behind sign-in. Intakes, local paths, security findings and account or usage details are never published here.
Original tools remain at their existing addresses. Recovered previews are versioned; pending artifacts are named openly.
