THE NUMBERS, DERIVED AND NOT TYPED

The count and the fingerprint appear in ten places across three repositories. Nobody types them. A script reads which names passed, adds them to the list, works out the fingerprint, and writes every place that has to agree. A test then proves that four independently written pieces of code compute the same fingerprint from the same names, and that all ten places carry it.

THE WINDOW: THURSDAY, 16:15 TO 18:25 ET

  • 16:15 ET — today's daily bar has closed, so the reports are final and cannot change under the run.
  • 18:25 ET — the last safe minute. At 18:30 the day the Geiger demands rolls forward from Wednesday to Thursday. Inside the window the new names are complete, because their history runs through Wednesday. After 18:30 all 424 names need Thursday in all eight rungs — and the machine that tops the history up each hour has not run since 10 September. Crossing 18:30 without it turns the Geiger to "awaiting data" for every name, new and old.
THE ONE THING THAT DECIDES FRIDAY MORNING Every percentage on the board is today's price against yesterday's close. Yesterday's closes are published as a single sealed file each night, stamped with the fingerprint of the name list that built it, and the chart service refuses a file whose stamp does not match what it expects. That file is built inside one machine, from the copy of the list in that machine's image. So the machine has to be updated before Friday's file is built. If it is not, Friday opens with a file the chart service refuses, and every percentage — all 424 — is blank until it is rebuilt.
