1 · WHAT WAS WRONG, IN ONE PICTURE

There are two different engines that can produce a company's Geiger, trend and momentum.

  • The live one. The provider Equalizer artifact, recomputed around the clock and served by the chart API. It is what the board shows. At 01:28Z this morning it read AAPL at +0.50 composite, trend +0.79, across 8 timeframes, under receipt f6cf97b57cf2.
  • The retired one. A database table called composite_staged. Measured this morning: it holds 386 rows for the daily timeframe, and 364 of them — every equity — have not moved since 24 August. Only 22 rows are current, and those are crypto, futures, rates and the VIX. For AAPL it still says +0.30.

The company READ tab was taking its date from the retired table. So the verdict carried a red label reading AS OF 2026-08-24 · 30D OLD while the board beside it showed this morning's reading. Worse, when the live engine had nothing for a company, the page did not say so: an absent number was quietly turned into zero, and zero prints as "the multi-timeframe read is constructive. Trend is mildly positive and momentum is mildly positive." That sentence was not a reading. It was an empty slot wearing the clothes of one.

THE ONE-LINE CAUSE

The code read num(row.composite) || 0. In JavaScript that turns "no value" into the number 0, and every sentence downstream then describes 0 as if it were a measurement.

5 · THE TEN-MINUTE JOB THAT MADE EVERYTHING LOOK NEW

A second, separate cause of "stale but fresh-looking": the Supabase job that writes the read blocks (read-engine, every ten minutes) stamped every row with the current time, whether the words had changed or not. So a sentence last written in June carried a timestamp from minutes ago.

The change is small and it is ready to deploy, but I did not deploy it:

  • a row whose text is identical to the stored one is not written at all, so its date stays the date its words actually changed;
  • the run now reports how many rows it wrote and how many it skipped, so a quiet run is visible rather than looking like a run that never happened;
  • if the comparison read fails, it writes everything, exactly as before — a failure can never be mistaken for "nothing changed";
  • a company's rows still travel together in one batch, so a half-written company is still impossible.
