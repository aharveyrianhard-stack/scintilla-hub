WHAT HAPPENS TO THE 12 COHORT TABS (the tickers.cohort tags)

  1. They stop being tabs. Each row keeps its tag chips (AI HW · MEGACAP · METALS …), and the TAG chips above filter whatever list or path is open: "my FAVORITES, only the AI HW ones" is one click, which no tab could do.
  2. Where a tag has a tree node (AI HW → COHORT_AI_HARDWARE, GROWTH, INTL, MACRO, INDEXES, THEMATIC, METALS, MEGACAP, AI SW), the node is also reachable from TREE PATH; BLUE CHIP, CRYPTO and AI POWER have no adopted tree node yet and stay tags only until the standard's E5 proposes one.
  3. Nothing is deleted: the tags are the same column, read the same way; only the strip above the board changes.
