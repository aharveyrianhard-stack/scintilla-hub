Adding a ticker to Scintilla: what it takes, and what to clean up

Read-only research draft, 27 Sep 2026 (live systems read about 15:35 UTC). Nothing was changed. Status: UNADMITTED draft. Every decision on this page belongs to Alan.

MEASURED counted or read from a live system ESTIMATE worked out from measured numbers, or a guess VERIFIED checked live or in the code THEORY inferred, not proven

The short version

  1. A new ticker has to pass through about 20 separate places ESTIMATE: 3 cloud machines, about a dozen database tables, the Hub page, the Station page, and several tests. There is no working one-button path. The old "one-click" onboard function is broken THEORY.
  2. The live universe (the official list of stock names) is 364 names MEASURED. The 24 Sep attempt to add 56 more (to 420) was half-applied. Only one machine, the bar service (the robot that builds price bars), still runs on 420. Everything else is on 364.
  3. That one mismatch is doing damage right now. Every refresh of the intraday frames (12h, 4h, 2h, 3h, 6h) expects 420 names, finishes 364, fails the other 56, and marks itself incomplete. So the chart API reports intraday bars as BEHIND VERIFIED.
  4. Recommendation: move the bar service back to 364 now (3 coordinated changes, each with a rollback). Before adding anyone, design the three tiers (SHOWN / COMPUTED / KNOWN). Today the system has no way to say "calculate this name but don't show it".

2 · Three tiers: SHOWN, COMPUTED, KNOWN

Today there is only one switch: active on the provider name table. That one switch means all of these at once: "the stream subscribes", "Geiger scores it", "settled close covers it" and "the Hub shows it". No show/hide flag exists anywhere VERIFIED. The three tiers below are a proposal that needs a design decision (a new column or table: a red-light schema change).

SHOWN

On the Hub board and the Station. Today's 364.

Requires: every step 1–17 above: identity row, full history, Geiger, chart API list, stream, Hub master row, cohort row, both page pins, and all the fundamentals, news and analyst feeds.

Must be: in /universe, an active equity in tickers, and in ticker_membership.

COMPUTED

Back-end only: bars and Geiger, used for blends and statistics, never on screen.

Requires: identity row, history (steps 2–4), bar service, Geiger scoring.

Must NOT be: in /universe, an active equity in tickers (or the Station's name-by-name check fails), or in ticker_membership (or it shows on a Station cohort scene as "not served") VERIFIED.

Blocker today: Geiger demands an exact count of every active name, and settled close also covers every active row. Both would need separating.

KNOWN

Holdings only: we know it sits in a fund at some weight. Nothing is computed.

Requires: one holdings row per fund (fund, name, weight). Possible homes: etf_holdings (1 ETF filled today) or index_constituents (created 24 Sep, 0 rows) MEASURED.

Missing: nobody fills holdings on a schedule. This is a prerequisite for the fund map.
